// This module implements the Present permutation layer
module Player(
    input [63:0] Inp,
    output [63:0] Oup
    ); 
// Inp is the 64-bit input vector to the permutation layer
// Oup is the 64-bit output of the permutation layer where the i-th bit of Inp is shifted to the P[i]-th bit of Oup, where P is a bijection in [0,63] to [0,63]
// Mathematically Oup[ P[i] ] = Inp[i] 
// The function P is given by the array P=[ 0,16,32,48, 1,17,33,49, 2,18,34,50, 3,19,35,51, 4,20,36,52, 5,21,37,53, 6,22,38,54, 7,23,39,55, 8,24,40,56, 9,25,41,57,10,26,42,58,11,27,43,59, 12,28,44,60,13,29,45,61,14,30,46,62,15,31,47,63 ]
